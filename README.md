# Rock Paper Scissors – Console-Based Python Game

This is a simple implementation of the classic Rock Paper Scissors game built using Python. The game runs in the terminal, accepts user input, and pits the player against a computer opponent using randomized logic.

---

## Learning Objective : 

To provide a beginner-friendly demonstration of core Python concepts including:
- User input and validation
- Randomized computer decisions
- Conditional logic
- Score tracking
- Loop-based game flow

---

## How to Run the Game

1. Make sure Python is installed on your machine.
2. Clone this repository or download the `.py` file.
3. Open a terminal window in the project directory.
4. Run the following command:

```bash
python "rock paper scissor game.py"
